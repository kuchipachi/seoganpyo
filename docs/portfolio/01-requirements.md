# 01. 요구사항 정의

## 주제 선정 배경

서강대 학생이 매 학기 겪는 불편에서 출발했다.

- 졸업 요건을 **엑셀로 수작업 계산** → 실수·누락 빈번
- 수강 이력을 포털에서 **한 줄씩 옮겨 적어야** 함
- 강의계획서·교수 정보가 **여러 페이지에 흩어져** 있음

→ **"시간표 이미지 한 장만 올리면, 졸업 요건·맞춤 강의·강의계획서 요약까지 한 번에"** 제공하는 AI 학업 컨설팅 플랫폼으로 주제 확정.

**대상 사용자**: 서강대 컴공 재학생 (수강신청·졸업요건 점검 시나리오)

## 기능 요구사항

| 영역 | 요구사항 |
|------|---------|
| 회원 | 이메일 인증 회원가입/로그인, JWT 본인 데이터 격리 |
| 강의·시간표 | 강의 검색, 찜·장바구니, **시간표 이미지 OCR 자동 인식** |
| 졸업·이력 | 수강이력 관리, 학점 시각화, **졸업 요건 자동 계산** |
| AI | 강의계획서 PDF 요약, 교수 연구분야 요약 |
| 커뮤니티 | 익명 게시판 (글·댓글·좋아요) |

## 비기능 요구사항

- **보안**: JWT 인증 / 본인 데이터 격리 / `.env` 시크릿 분리 / 의존성 CVE 점검
- **가용성**: Docker Compose 배포 / 관측 스택(Prometheus·Grafana·Loki) 모니터링
- **유지보수**: 계층 분리(라우터·서비스·모델), 팀 공통 컨벤션 문서화
