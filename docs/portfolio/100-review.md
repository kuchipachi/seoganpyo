# Review

- **초기 DB 설계의 중요성** : 시작 단계에서 테이블과 관계를 꼼꼼히 설계하는 습관을 가지게 됨
- **공통 규칙의 일원화** : 팀 공통 규칙을 한 곳에서 통일해 관리하게 됨
- **DevOps 전 과정 경험** : 운영까지 고려하는 시야를 얻게 됨
- **외부 의존성 관리** : 버전 핀이 기본이되, 핀으로 해결되지 않으면 의존성 개수 자체를 줄이고, 빌드가 깨지면 '코드 / 환경 / 캐시'부터 분리해 진단하는 습관을 얻게 됨
- **메트릭 검증** : 메트릭은 수집하는 것만큼 라벨 스키마 검증이 중요하다는 것을 알게 됨
