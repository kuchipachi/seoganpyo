# 99. 개발 중 이슈

## 🗣️ 팀원과의 다툼 — "재수강 학점, 어떻게 셀 거냐"

**상황**: 졸업요건 페이지와 대시보드가 **이수 학점을 서로 다르게 표시**하는 버그가 발견됐다. 원인은 재수강 과목 처리 방식 — "재수강을 학점에 두 번 더할 거냐, 가장 최근 것만 셀 거냐"를 두고 팀 의견이 갈렸다.

**과정**: 화면마다 제각각 계산하던 로직이 충돌의 근원이었다. 감정싸움 대신 학사 규정을 근거로 **"같은 과목 그룹에서 가장 최근 row 1개만 카운트"** 라는 단일 룰에 합의했다.

**결과**: 졸업요건·대시보드 양쪽에 **동일한 dedup 룰을 일괄 적용**해 표시 불일치를 해소했다. "각자 옳다고 우기기"를 "규정 기준 하나로 통일"로 끝낸 사례.

## 🛠️ 형상관리의 어려움 — "내 컴퓨터에선 됐는데"

**상황 1 · OS별 빌드 깨짐**: 팀원마다 개발 환경(Mac/Windows)이 달라 Docker 이미지 빌드가 누군가에겐 되고 누군가에겐 깨졌다.

**대응**: backend Dockerfile을 **multi-stage + 베이스 이미지 버전 핀(bookworm)** 으로 고정해, 어느 환경에서 빌드해도 같은 결과가 나오도록 **재현성**을 확보했다.

**상황 2 · 배포 환경에서만 터지는 버그**: 로컬은 멀쩡한데 배포 서버에서 **OCR 이미지 업로드가 막혔다**. 원인은 bind-mount 디렉토리 권한 — 컨테이너 유저(appuser, uid 10001)에게 쓰기 권한이 없었다.

**대응**: 배포 스테이지에서 마운트 디렉토리 ownership을 컨테이너 유저에 맞추고, Jenkins 포트 충돌(8080→8088)·orphan 컨테이너 강제 정리까지 배포 파이프라인을 정비했다.

## ⚡ 효율성 개선 — 보안·성능·정합성

| 개선 | 내용 | 효과 |
|------|------|------|
| **보안 결함 차단** | 보안 헤더 미들웨어 추가 | ZAP DAST **High 12건 → 0건** |
| **의존성 취약점 패치** | PyJWT·multipart·idna 등 | Python CVE **9건** 해소 |
| **관심과목 표시 누락 수정** | cart 응답에 course JOIN 추가 | 빈 화면으로 보이던 관심과목·시간표 정상 표시 |
| **OCR 매칭 정확도 개선** | 끝 숫자·길이 페널티·모호성 임계 | 시간표 과목 오매칭 감소 |
| **부하 테스트 도입** | JMeter + InfluxDB 스택 | API 성능을 수치로 측정·시각화 |

---

> 핵심 교훈: 환경 차이는 **버전 핀으로 재현성**을, 계산 이견은 **규정 기준 단일화**로, 보안·성능은 **수치로 측정**해 풀었다.
