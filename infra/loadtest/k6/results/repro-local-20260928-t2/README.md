| 파일 | 내용 |
| --- | --- |
| `result-t2full-<이미지>-r<요청/초>-<라운드>.txt` | **본 결과** — 운영과 같은 응답 크기(130KB), 3라운드 교차 |
| `result-t2x-*` | 같은 이미지를 다른 도착률로 — 지연 차이가 이미지가 아니라 부하(CPU 절전) 때문임을 확인 |
| `result-t2cap-t1t2-r{100,150,200}.txt` | T1+T2 처리 한계 |
| `light-payload/` | ⚠️ details 가 빈 DB(응답 15KB)로 잰 1차 결과 — 처리량을 부풀려 재므로 **본 결과로 쓰지 않음**. 방향(개선)은 같음 |
